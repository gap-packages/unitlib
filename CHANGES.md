## 5.1.0 (2026-07-14)

- Require GAP >= 4.12
- Drop the dependencies on IO and GAPDoc; make the dependency on SmallGrp
  explicit
- Fix manual examples, which are now extracted with AutoDoc

## 5.0.0 (2025-06-12)

- Include the data for groups of order 243, recomputed, in the package instead
  of offering it as an optional download
- Remove obsolete ParGAP code and its description in the manual

- Janitorial changes

## 4.1.0 (2022-04-26)

- Require GAP >= 4.11 and LAGUNA >= 3.9.4, and adapt to changes in LAGUNA
- Drop the external `gzip` requirement for groups of order 128, which GAP
  >= 4.10 handles itself, also on Windows
